The objective is understanding, not just execution.
A statistical method is useful only when we understand what question it answers, what assumptions it makes, and what conclusions its results support.
This repository is a work in progress. Each script represents part of an ongoing effort to connect statistical theory with practical Python programming.

The project uses Python and relevant scientific computing libraries, including:
Pandas — working with and organizing datasets
NumPy — numerical computing
SciPy — statistical tests and correlation analysis
Statsmodels — statistical modeling and regression analysis
Matplotlib / Seaborn — data visualization as needed

Who Is This For?
This repository is intended for students, beginners, and anyone interested in learning statistics through practical implementation.
You do not need to be an expert programmer. The scripts are designed to support learning, with code comments and examples that explain the reasoning behind the analysis.

Disclaimer
The datasets and examples used for learning may be illustrative rather than real-world research data. 
Results should be interpreted in the context of each example and should not automatically be treated as evidence about real populations.
